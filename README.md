# VSXVPRINCE — сайт с анимациями на Remotion

Редизайн vsxvprince.com. Все анимации — композиции Remotion: на сайте они крутятся
в `@remotion/player` и реагируют на клики, а в Studio их можно отрендерить в mp4.

## Запуск

```bash
npm install --legacy-peer-deps
npm run dev        # сайт: http://localhost:5173
npm run studio     # Remotion Studio: все композиции
npm run build      # продакшен-сборка в dist/
```

## Что анимировано и на что реагирует

| Где | Композиция | Реакция |
|---|---|---|
| Первый экран | `HeroIntro` | клик в любую точку — ударная волна, тряска букв, RGB-сдвиг |
| Меню | `PageWipe` | переход шторками с орнаментом и названием раздела |
| Тур | `TourPromo` | клик по городу — ролик заново: барабан с датой, город по буквам, площадка печатается |
| Мерч | `ProductReveal` | клик по товару — круговое раскрытие фона, шторка по диагонали |
| Музыка | `MusicPulse` | наведение на платформу — название и цвет эквалайзера меняются |
| Везде | `ClickBurst` | вспышка с орнаментом в точке клика |

`TourStory` (1080×1920) — сторис тура для Instagram: `npm run render:story`.

## Контент

Тексты, даты и ссылки — в `src/data.ts`. Картинки пока грузятся с vsxvprince.com;
для продакшена скачайте их в `public/` и замените ссылки на `staticFile('...')`.

## Лицензия Remotion

Remotion бесплатен для частных лиц и компаний до 3 сотрудников; для бо́льших
команд нужна компания-лицензия — https://remotion.pro
